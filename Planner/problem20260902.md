현재 코드에서 미완성인 부분은 크게 다음과 같습니다.

1. UtilityAI가 한 번만 판단함
## 2026/09/03 기준으로 이거부터 해결한다.
base_mode.py:216~223
self.company_ai_action = self.company_ai.decide_action()
모델 생성 시 한 번만 실행됩니다. 이후 수요, 현금, 이익이 바뀌어도 AI가 다시 판단하지 않습니다.

2. production, debt 액션이 실제 동작하지 않음
현재 실제로 연결된 것은:
- hire: 고용 flow 작동
- layoff: 해고 flow 작동
하지만:
- production: 생산량 변화 없음
- debt: 부채 발행 flow 없음
즉 AI가 "debt"를 선택해도 실제 부채는 변하지 않습니다.

3. Utility 공식이 임시값에 의존함
company_ai.py
cash / 1000
profit / 1000
previous_demand / 1000
workers * 10
1000, 10이 현재 임시 기준값입니다. 실제 기업 규모나 생산량에 따라 조정되어야 합니다.

4. 임금 계산이 실제 workers 변화를 반영하지 않음
base_mode.py:191~193
wage_cost.equation = self.workers_wage * self.workers
self.workers는 초기값이므로, 고용이나 해고가 발생해도 임금 비용은 계속 초기 인원 기준입니다. BPTK의 workers 값을 사용해야 합니다.

5. 고용 공식이 전체 생산능력을 고려하지 않음
base_mode.py:74
demand - production_per_worker
현재는 수요와 근로자 1명의 생산량만 비교합니다. 실제로는 다음처럼 전체 생산능력과 비교해야 합니다.
demand - workers * production_per_worker

6. 현금과 부채 구조가 미완성
- cash는 이익만큼 변함
- debt는 초기값 1.0에서 변하지 않음
- 대출, 상환, 이자 비용이 없음

7. 수요가 매번 랜덤이고 seed가 없음
base_mode.py:161
sd.normal(0.0, 5.0)
실행할 때마다 결과가 달라져서 디버깅과 비교가 어렵습니다.

8. 프론트엔드에서 AI 액션은 단순 표시만 함
현재 ai_action은 테이블에 표시되지만:
- 시간별로 AI가 다시 판단하지 않음
- 액션 변화 그래프 없음
- 시뮬레이션 설정값을 프론트엔드에서 변경할 수 없음
- /data 요청 때마다 새 시뮬레이션을 실행하지 않음
우선순위로 보면 1번 동적 판단, 2번 production/debt 실제 반영, 4번 임금 계산 수정이 가장 중요합니다.
